# Quiz Application (Java Console)

A beginner-friendly multiple-choice quiz application built with Java. It displays questions, accepts answers, calculates a score, and shows an answer review.

## Concepts used

- Arrays for each question's answer options
- `ArrayList` for storing quiz questions and answer-review messages
- Classes and objects
- Loops and conditional statements
- `Scanner` input handling
- `try-catch` validation for invalid answers

## Features

- Displays three multiple-choice questions
- Validates that answers are within the available range
- Calculates and displays the final score
- Shows whether each answer was correct or incorrect
